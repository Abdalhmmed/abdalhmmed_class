# البوابة الأكاديمية لمختبرات وملازم البرمجة بلغة Java
### جامعة عدن - كلية علوم الحاسوب وتكنولوجيا المعلومات - قسم نظم المعلومات (الجانب العملي)
**إعداد وتطوير:** م. عبدالحميد هلال دعبان  
**العام الجامعي:** 2026-2027م  

---

## 📌 نبذة عن المشروع
منصة وبوابة أكاديمية تفاعلية حديثة مخصصة لطلاب كلية علوم الحاسوب وتكنولوجيا المعلومات بجامعة عدن لمادة **هياكل البيانات والخوارزميات (Data Structures)** والتطبيقات العملية بلغة **Java**.

تم إعداد هذا المستودع ليعمل مباشرة وبشكل مجاني عبر خدمة **GitHub Pages**.

---

## 📂 هيكلة الملفات
- **`index.html`**: الصفحة الرئيسية للبوابة (واجهة المقررات والملازم، التبديل الليلي/النهاري، وروابط الوصول السريع).
- **`الملزمة_العملية_الأولى_التعقيد_والمصفوفات_Java.html`**: ملزمة الشرح التفاعلي الحي، تشمل محاكي تنفيذ الخوارزميات، تتبع المتغيرات في الذاكرة، وقلم الشرح.
- **`الملزمة_التعليمية_المصفوفات_Java_جاهز_للطباعة_PDF.html`**: نسخة منسقة خصيصاً للتصدير والحفظ كملف PDF عالي الجودة بقياس A4 والطباعة الورقية.

---

## 🚀 كيفية التفعيل على GitHub Pages
1. ادخل إلى إعدادات المستودع (**Settings**).
2. اختر من القائمة الجانبية تبويب **Pages**.
3. تحت قسم **Build and deployment**:
   - اضبط المصدر (**Source**) على: `Deploy from a branch`.
   - حدد الفرع (**Branch**) على: `main` والمجلد على: `/ (root)`.
4. انقر على **Save**.
5. خلال دقائق سيظهر رابط موقعك المباشر في أعلى الصفحة.
