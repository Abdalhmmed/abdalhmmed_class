## 📌 الهيكلية البرمجية للمستودع (Project Structure)
تمت إعادة هيكلة المشروع وفق المعايير البرمجية القياسية (Web Standards) لضمان سهولة الإضافة والصيانة والتوسع المستقبلي:

```text
abdalhmmed_class/
│
├── index.html                           # البوابة الرئيسية لعرض المقررات والملازم
├── README.md                            # دليل المشروع والتوثيق الأكاديمي
│
├── courses/                             # مجلد المقررات الدراسية
│   └── data-structures/                 # مقرر هياكل البيانات والخوارزميات (Java)
│       └── lecture-01/                  # الملزمة الأولى: المصفوفات والتعقيد (Big-O)
│           ├── interactive.html         # نسخة الشرح التفاعلي والمحاكاة الحية
│           └── print-pdf.html           # نسخة التصدير والحفظ كـ PDF والطباعة الورقية
│
└── assets/                              # الموارد المشتركة للمشروع (توسعات مستقبلية)
    ├── css/                             # ملفات الأنماط والتنسيق المشتركة
    └── js/                              # السكربتات البرمجية والمكتبات
```

---

## 🚀 كيفية إضافة محاضرات أو مقررات جديدة مستقبلاً
1. **لإضافة محاضرة جديدة لمقرر هياكل البيانات:**
   - أنشئ مجلداً جديداً داخل `courses/data-structures/` مثل: `lecture-02/`.
   - ضع بداخله ملف الشرح التفاعلي `interactive.html` وملف الطباعة `print-pdf.html`.
2. **لإضافة مقرر جديد مستقبلاً (مثل OOP أو Databases):**
   - أنشئ مجلداً جديداً داخل `courses/` مثل: `courses/oop/`.
   - اربط الروابط الجديدة في الصفحة الرئيسية `index.html`.

---

## 🌐 التفعيل على GitHub Pages
1. ادخل إلى إعدادات المستودع (**Settings**).
2. اختر من القائمة الجانبية تبويب **Pages**.
3. تحت قسم **Build and deployment**:
   - اضبط المصدر (**Source**) على: `Deploy from a branch`.
   - حدد الفرع (**Branch**) على: `main` والمجلد على: `/ (root)`.
4. انقر على **Save**.
