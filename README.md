## 🚀 كيفية تشغيل المنصة

1. **التشغيل المباشر محلياً (Local Run):**
   - لا حاجة لتثبيت أي حزم أو خوادم محلية؛ فقط افتح `index.html` في أي متصفح ويب حديث.
2. **التفعيل على GitHub Pages:**
   - ادخل إلى إعدادات المستودع (**Settings**).
   - اختر من القائمة الجانبية تبويب **Pages**.
   - تحت قسم **Build and deployment**:
     - اضبط المصدر (**Source**) على: `Deploy from a branch`.
     - حدد الفرع (**Branch**) على: `main` والمجلد على: `/ (root)`.
   - انقر على **Save**.
