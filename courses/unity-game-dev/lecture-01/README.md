## 🎯 النتيجة النهائية المستهدفة للطالب
إنشاء مشهد لعبة ثنائية الأبعاد (2D) متكامل في Unity يحتوي على:
1. هيكل منظم من الطبقات: `Ground_Tilemap` للأرضية، `Decoration_Tilemap` للزينة، و`Background_Tilemap` للخلفية.
2. شبكة رسم باستخدام **Tile Palette** وضبط إعدادات الصور من نمط Pixel Art (`Point (no filter)` مع توحيد `Pixels Per Unit`).
3. إعداد **Rule Tile** ذكي يتعرف تلقائياً على الجيران المحيطين لاختيار الحواف والزوايا والوسط بدون رسم يدوي مجهد.
4. نظام تصادم فيزيائي متماسك للأرضية باستخدام `Tilemap Collider 2D` مدمجاً عبر `Composite Collider 2D` و `Rigidbody 2D (Static)`.
5. كائن متحرك (شخصية أو عنصر بيئي) بـ **Animation Clip** مكون من تسلسل إطارات Sprites مع التحكم في `Samples` و `Loop Time`.
