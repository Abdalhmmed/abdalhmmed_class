## 📌 أبرز محتويات المحاضرة
1. **مدخل التعقيد وكفاءة الكود:** ما هو $Big\text{-}O$ ولماذا لا نقيس الكفاءة بالثواني؟
2. **التشريح الفيزيائي للذاكرة:** كيف تُخزن المصفوفة في RAM وكيف يُحسب عنوان الخلية في خطوة واحدة؟
3. **العمليات الـ 9 المشروحة تفاعلياً:**
   - الوصول المباشر والتعديل $O(1)$
   - المرور وحساب المجموع والمتوسط $O(n)$
   - البحث الخطي (Linear Search)
   - إيجاد أكبر وأصغر قيمة (Min / Max)
   - عكس عناصر المصفوفة باستخدام مؤشرين (Two Pointers)
   - إدراج عنصر في موقع محدد (Insert at Pos)
   - حذف عنصر من موقع محدد (Delete at Pos)
   - الترتيب الفقاعي (Bubble Sort)
   - المصفوفات ثنائية الأبعاد (2D Arrays)
4. **مرجع أكواد CRUD:** دوال جاهزة في Java للإضافة، التعديل، الحذف، والبحث مع برنامج `Main` كامل للتجربة الفورية.
