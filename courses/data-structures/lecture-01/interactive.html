الدرس 1: ما هو رمز Big-O وكيف نقيس كفاءة الكود؟

💡 ما هو وما هو اختصار له؟

الحرف O يرمز لكلمة "Order of Growth" (رتبة أو معدل النمو)، ويُعرف بـ Big-O Notation.
هو مقياس رياضي عالمي يجيب عن السؤال:
«إذا كبُرت البيانات وزادت في البرنامج (n)، فبأي وتيرة وسرعة سيزداد عدد الخطوات التي يحتاجها الحاسوب لتنفيذ الكود؟»

❌ لماذا لا نقيس الكفاءة بالثواني؟

لأن الثواني خادعة وتعتمد على قوة المعالج، نوع نظام التشغيل وسرعة الجهاز. نفس الكود قد يستغرق 0.1 ثانية على حاسوب حديث و 4 ثوانٍ على هاتف قديم.

✅ لماذا نستخدم رمز Big-O؟

لأنه يقيس الخطوات والعمليات المنطقية المستقلة عن العتاد، ويعطينا حكماً ثابتاً وعادلاً وموثوقاً على كفاءة الخوارزمية.

🔍 ماذا يعني الحرف (n)؟

n يمثل حجم المدخلات (Number of elements). في المصفوفات: إذا كانت المصفوفة تحتوي على 5 عناصر فإن n = 5، وإذا احتوت على 1000 عنصر فإن n = 1000.

📈 رسم بياني ديكارتي (X و Y): كيف تنمو العمليات مع زيادة حجم البيانات n؟

محاور X و Y تفاعلية

المحور الأفقي (X) يمثل حجم البيانات n، والمحور الرأسي (Y) يمثل عدد العمليات المطلوبة. حرّك المؤشر لمشاهدة حركة النقطة على كل منحنى ومقارنة تسارع النمو:

● O(1) ثابت ● O(log n) لوغاريتمي ● O(n) خطي ● O(n²) تربيعي
O(1) · ثابت 1
Y = 1 دائماً مهما زاد X
O(log n) · لوغاريتمي 4
Y = ⌈log₂ X⌉ نمو بطيء جداً
O(n) · خطي 10
Y = X خط مستقيم متناسب
O(n²) · تربيعي 100
Y = X² منحنى يصعد كالسهم
لاحظ على الرسم البياني: عند X = 10، نجد O(1) خطوة واحدة فقط، و O(n) تحتاج 10 خطوات، بينما O(n²) تقفز إلى 100 خطوة!

ماذا نعدّ بالضبط داخل الكود؟ (العدّادات التي ستراها في المحاكاة)

🔍 مقارنة (Comparisons)

كل شرط يُفحص في المعالج: i < n أو arr[i] == target أو arr[j] > arr[j+1].

📖 قراءة (Reads)

كل وصول لقيمة عنصر من خانات المصفوفة في الذاكرة: arr[i].

✍️ كتابة (Writes)

كل إسناد وتخزين قيمة في خانة أو متغير: arr[i] = x أو sum += ….

Σ المجموع الفعلي

مجموع العمليات الثلاث معاً، ومنه نستخرج معادلة النمو ونختصرها إلى Big-O.

الحالات الثلاث في تقييم الخوارزمية (لماذا لا يكفي رقم واحد؟)

الحالةالمعنى العلميمثال من البحث الخطيالأهمية
أفضل حالة Best Caseأسهل سيناريو مدخلات ممكن، وأقل عدد عمليات ينفذه الكود.العنصر المطلوب يقع في أول خانة arr[0] مباشرة.توضح أقصى كفاءة ممكنة.
الحالة المتوسطة Averageالعدد المتوقع للعمليات عند تشغيل البرنامج على مدخلات عشوائية طبيعية.العنصر المطلوب في منتصف المصفوفة تقريباً ($n/2$).تعكس الأداء اليومي الواقعي.
أسوأ حالة Worst Caseأصعب سيناريو مدخلات ممكن، وأقصى حد أعلى للعمليات (Upper Bound).العنصر المطلوب في آخر خانة أو غير موجود في المصفوفة إطلاقاً.الأهم في الحسابات لضمان أمان النظام.
قاعدة الاختصار الذهبية في Big-O: نهمل الثوابت والمعاملات والحدود الصغيرة ونركز فقط على العنصر المسيطر الأسرع نمواً.
مثال: إذا كان المجموع الدقيق لعمليات حلقة هو 3n + 5، فإننا نحذف الرقم 5 ومعامل الضرب 3، ونقول أن التعقيد هو O(n). وإذا كان ½n² + 3n نكتفي بـ O(n²).
📦 الوحدة الثانية: ماهية المصفوفة (المفهوم والتصميم)

الدرس 2: ما هي المصفوفة ولماذا نحتاجها؟

2.1 مشكلة المتغيرات المنفصلة وحلها بالمصفوفة

لنفترض أننا نريد تخزين درجات 5 طلاب. بدون مصفوفة نحتاج 5 متغيرات منفصلة، ولو زادوا إلى 100 طالب نحتاج 100 متغير ولا نستطيع المرور عليها بحلقة تكرار.

❌ بدون مصفوفة (كابوس برمجي)

int mark1 = 85; int mark2 = 92; int mark3 = 78; int mark4 = 64; int mark5 = 90; // لحساب المجموع: int sum = mark1 + mark2 + mark3 + mark4 + mark5;

متغيرات متفرقة، لا يمكن المرور عليها بحلقة، والكود يطول مع كل طالب جديد.

✅ مع مصفوفة (الحل الذكي)

int[] marks = {85, 92, 78, 64, 90}; int sum = 0; for (int i = 0; i < marks.length; i++) { sum += marks[i]; }

اسم واحد جامع، وحلقة واحدة من سطرين تجمع درجات 5 طلاب أو حتى مليون طالب!

التعريف الأساسي: المصفوفة هي بنية بيانات خطية تخزن مجموعة عناصر متجانسة (من نفس النوع)، في خانات متجاورة في الذاكرة تحت اسم واحد، ونصل لكل عنصر عبر رقمه الترتيبي (الفهرس Index) الذي يبدأ دائماً من 0.

2.2 هيكل المصفوفة في الذاكرة: خانات متجاورة، عنوان البداية (Base)، ولماذا الفهرس يبدأ من 0؟

الحاسوب في الذاكرة يعرف عنوان أول خانة فقط (Base Address). ولأن كل الخانات بنفس الحجم ومتلاصقة تماماً بدون أي فراغ، فإن الفهرس (Index) ليس مجرد رقم ترتيبي؛ بل هو مقدار الإزاحة (Offset) عن نقطة البداية:

العنوان الفيزيائي للخانة = Base + (Index × نوع_البيانات_حجم)
marks مرجع لأول خانة (Base Address) [i] الفهرس: من 0 إلى length − 1 marks[i] القيمة المخزنة في الخانة marks.length عدد الخانات = 5
اضغط على أي خانة أعلاه لترى كيف يحسب المعالج عنوانها الفيزيائي في خطوة واحدة O(1).

• أول خانة: إزاحتها 0 خانات عن البداية، لذلك نكتب Base + 0 = Base ومن هنا جاء الفهرس 0.
• ثاني خانة: إزاحتها 1 خانة عن البداية $\rightarrow$ Base + 1 × 4.
النتيجة العظيمة: لأن المعالج يضرب الفهرس ويجمعه في دورة ساعة واحدة، فإن الوصول وقراءة أي خانة في المصفوفة يستغرق دائماً زمن ثابت O(1)!

2.3 مراحل حياة المصفوفة في Java: التصريح (Declaration) ⬅️ الحجز (new) ⬅️ التعبئة

المرحلة 1

التصريح (Declaration)

int[] marks;

نعلن فقط عن اسم سيكون مصفوفة. في الذاكرة: لم تُحجز أي خانة بعد (المرجع قيمته null).

المرحلة 2

الحجز في الـ Heap (بواسطة new)

marks = new int[5];

تُحجز 5 خانات متتالية في الـ Heap فوراً، وتأخذ قيماً افتراضية تلقائية (0 للأعداد، false للـ boolean).

المرحلة 3

التعبئة (Initialization)

marks[0] = 85; marks[1] = 92;

نستبدل القيم الافتراضية بالقيم الحقيقية عبر الفهرس، أو ندمج المراحل الثلاث بسطر واحد: int[] marks = {85, 92, ...};

🛠️ مختبر الإنشاء والحجز المباشر:
النوع (Data Type)القيمة الافتراضية بعد new مباشرةحجم الخانة في الذاكرة

booleanfalse1 بايت
char'\u0000' (حرف فارغ)2 بايت
String (أو أي كائن)null (لا يشير لشيء)4 أو 8 بايت (مرجع)

2.4 المرور على عناصر المصفوفة: حلقة for التقليدية بالفهرس

for (int i = 0; i < marks.length; i++) { System.out.println("العنصر في الفهرس [" + i + "] = " + marks[i]); marks[i] += 5; // يمكننا القراءة والتعديل على الخانة مباشرة عبر الفهرس i! }

آلية العمل: المتغير i يبدأ من 0 (أول خانة) ويزداد بمقدار 1 في كل دورة حتى يصل إلى length - 1. ميزتها الأساسية أننا نعرف موقع كل عنصر في الذاكرة بدقة، مما يمكننا من القراءة، التعديل المباشر، أو المرور بالعكس.

🎬 محاكاة حية للمرور بحلقة for التقليدية:
اضغط زر التشغيل لمشاهدة كيف يتحرك المؤشر i دورة بدورة.

2.5 خصائص المصفوفة: ما الذي تجيده وما الذي تعجز عنه؟

✅ المزايا والقوة

• وصول مباشر فوري لأي عنصر O(1)
• تخزين متجاور وسريع في الذاكرة (Cache friendly)
• حجز مساحة محددة دون استهلاك ذاكرة إضافية للروابط

⚠️ القيود والعيوب

• الحجم ثابت ولا يمكن تمديده أو تقليصه
• الإدراج والحذف مكلفان O(n) ويتطلبان بناء مصفوفة جديدة وإزاحة العناصر
• نوع البيانات موحد ولا يقبل خلط أنواع

🎯 متى نفضل استخدامها؟

• عندما يكون عدد العناصر معروفاً مسبقاً
• عندما نحتاج للقراءة والتعديل السريع بالموقع
• كبنية أساسية لبناء هياكل أخرى (مثل Stack, Queue, Tables)

تذكّر دائماً لتجنب خطأ الحدود (IndexOutOfBoundsException): لأن الفهرس يبدأ من 0، فإن آخر خانة دائماً هي length - 1. لذلك نكتب شرط الحلقة دائماً i < arr.length وليس i <= arr.length.

3. العمليات على المصفوفة

كل عملية في قسم مستقل خاص بها، ولكل قسم ثلاث شرائح: ① الفكرة ← ② التنفيذ خطوة بخطوة ← ③ التحليل والتعقيد. اختصارات لوحة المفاتيح تعمل على القسم الذي يقف عليه مؤشر الفأرة: ← التالي · → السابق · مسافة تشغيل/إيقاف.

💻 مرجع الأكواد الأساسية (CRUD Operations)

أكواد العمليات الأربع الرئيسية على المصفوفة (دوال جاهزة مع الشرح)

دليل عملي سريع يحتوي على الدوال البرمجية (Methods) النموذجية المكتوبة بلغة Java للعمليات الأربع: الإضافة، التعديل، الحذف، والبحث، مع شرح مدخلات ومخرجات كل دالة وما تفعله بالتفصيل.

➕ 1. كود إضافة بيانات (Insert at Position)

التعقيد الزمني: O(n)

تستقبل المصفوفة القديمة، والموقع pos، والقيمة الجديدة val. تُنشئ مصفوفة جديدة أطول بخانة وتُرجعها بعد إزاحة العناصر لليمين:

// دالة لإضافة عنصر في أي موقع محدد داخل المصفوفة public static int[] insert(int[] arr, int pos, int val) { // 1. حجز مصفوفة جديدة أطول بخانة واحدة int[] result = new int[arr.length + 1]; // 2. نسخ العناصر السابقة لموقع الإضافة كما هي for (int i = 0; i < pos; i++) { result[i] = arr[i]; } // 3. وضع القيمة الجديدة في مكانها المخصص result[pos] = val; // 4. نسخ العناصر اللاحقة مع إزاحتها لليمين خانة واحدة (+1) for (int i = pos; i < arr.length; i++) { result[i + 1] = arr[i]; } return result; // إرجاع المصفوفة الجديدة بعد الإضافة }

✏️ 2. كود تعديل بيانات (Update at Index)

التعقيد الزمني: O(1)

التعديل لا يتطلب إنشاء مصفوفة جديدة ولا إزاحة؛ نصل للخانة مباشرة عبر الفهرس ونستبدل قيمتها القديمة بالجديدة في خطوة واحدة:

// دالة لتعديل قيمة عنصر في فهرس محدد مباشرة public static void update(int[] arr, int index, int newVal) { // فحص أمان: التأكد أن الفهرس داخل الحدود المسموحة if (index >= 0 && index < arr.length) { arr[index] = newVal; // استبدال مباشر في خطوة واحدة O(1) } else { System.out.println("خطأ: الفهرس خارج حدود المصفوفة!"); } }

🗑️ 3. كود حذف بيانات (Delete at Position)

التعقيد الزمني: O(n)

تستقبل المصفوفة والموقع المراد حذفه pos. تُنشئ مصفوفة جديدة أصغر بخانة، وتنسخ العناصر مع تخطي العنصر المحذوف وإزاحة ما بعده لليسار:

// دالة لحذف عنصر في موقع محدد وإرجاع المصفوفة بعد الحذف public static int[] delete(int[] arr, int pos) { // 1. حجز مصفوفة جديدة أصغر بخانة واحدة int[] result = new int[arr.length - 1]; // 2. نسخ العناصر السابقة لموقع الحذف كما هي for (int i = 0; i < pos; i++) { result[i] = arr[i]; } // 3. نسخ العناصر اللاحقة مع إزاحتها لليسار خانة واحدة (-1) لملء الفراغ for (int i = pos + 1; i < arr.length; i++) { result[i - 1] = arr[i]; } return result; // إرجاع المصفوفة الجديدة بدون العنصر المحذوف }

🔍 4. كود البحث عن بيانات (Linear Search)

التعقيد: أفضل O(1) / أسوأ O(n)

تبحث عن القيمة target عنصراً عنصراً. إذا وجدتها تُرجع رقم الفهرس index فوراً، وإذا انتهت المصفوفة دون العثور عليها تُرجع -1:

// دالة للبحث الخطي: تُرجع فهرس العنصر إن وُجد، أو -1 إن لم يوجد public static int search(int[] arr, int target) { for (int i = 0; i < arr.length; i++) { if (arr[i] == target) { return i; // وُجد العنصر! نرجع الفهرس ونتوقف فوراً } } return -1; // انتهى المرور على كل العناصر ولم نجد القيمة }
🌟 برنامج متكامل في Main يجرّب العمليات الأربع معاً:
/** * مختبر هياكل البيانات والخوارزميات بلغة Java * إعداد وتطوير: م. عبدالحميد هلال دعبان (بكالوريوس علوم حاسوب) * مادة عامة وشاملة لكافة التخصصات الحاسوبية والتقنية */ public class Main { public static void main(String[] args) { int[] numbers = {10, 20, 30, 40}; // 1. إضافة 99 في الموقع رقم 1: numbers = insert(numbers, 1, 99); // النتيجة: {10, 99, 20, 30, 40} // 2. تعديل العنصر في الفهرس رقم 0 ليصبح 55: update(numbers, 0, 55); // النتيجة: {55, 99, 20, 30, 40} // 3. حذف العنصر في الموقع رقم 2 (الذي قيمته 20): numbers = delete(numbers, 2); // النتيجة: {55, 99, 30, 40} // 4. البحث عن الرقم 30: int found = search(numbers, 30); if (found != -1) { System.out.println("وُجد في الفهرس: " + found); // يطبع الفهرس 2 } else { System.out.println("غير موجود"); } } }
