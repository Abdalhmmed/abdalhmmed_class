1. Concept of 2D Matrices & Physical Memory Architecture

A one-dimensional array (int[]) models a single linear list of values. However, real-world engineering problems—such as digital images (pixels arranged in rows and columns), student gradebooks across multiple subjects, chessboard states, and mathematical matrices—require organizing data across two orthogonal axes: Rows (r) and Columns (c).

1.1 Two Memory Models: Java "Array of Arrays" vs. Contiguous Row-Major Order

Physical RAM is strictly one-dimensional—a flat sequence of byte addresses. Programming languages map a 2D logical grid onto 1D physical RAM using one of two architectural models:

Model A: Java Heap "Array of Arrays"

In Java, int[][] m = new int[3][4] allocates an outer spine array of 3 object references (m[0], m[1], m[2]). Each reference points to an independent 1D int[4] array on the Heap:

  • m[0] → 0x2000 (stores Row 0: [10, 20, 30, 40])
  • m[1] → 0x3080 (stores Row 1: [50, 60, 70, 80])
  • m[2] → 0x4120 (stores Row 2: [90, 15, 25, 35])
Access Cost: Two O(1) pointer hops → Total Time = O(1).

Model B: Flat Row-Major Contiguous Formula

In C/C++ or flattened 1D buffers in Java, all rows are stored back-to-back in a single contiguous block of size R × C. To jump to (r, c), we skip r full rows (each of width C) plus c columns:

Address(r, c) = Base + ((r × C) + c) × size
Example for m[1][1] (Base=1000, C=4, size=4B):
1000 + ((1×4) + 1)×4 = 1000 + 20 = 1020.
Crucial Distinction Between m.length and m[r].length: In Java, m.length returns the number of rows (R) (the length of the outer spine array), whereas m[r].length returns the number of columns in row r (C). Always write c < m[r].length in the inner loop so your code safely handles both rectangular and jagged matrices.

2. Lifecycle, Jagged Arrays & Nested Loop Traversals

1. Declaration

int[][] m;

Reserves a reference variable m on the Stack (initialized to null).

2. Heap Allocation

m = new int[3][4];

Allocates 3 rows × 4 columns on the Heap; all 12 cells default to 0.

3. Literal Initialization

int[][] m = {{1,2},{3,4}};

Allocates and populates rows with explicit initial values in one statement.

2.1 Jagged (Ragged) Arrays in Java

Because Java represents a 2D array as an array of row references, each row can be allocated with a different column length. Such a structure is called a Jagged Array (or Ragged Array), which saves memory when storing triangular matrices or variable-length records:

// Allocating a Jagged Array where each row has a different number of columns: int[][] jagged = new int[3][]; // Step 1: Allocate spine array of 3 row references jagged[0] = new int[2]; // Row 0 has 2 columns (jagged[0].length == 2) jagged[1] = new int[4]; // Row 1 has 4 columns (jagged[1].length == 4) jagged[2] = new int[1]; // Row 2 has 1 column (jagged[2].length == 1)

2.2 Row-Major vs. Column-Major Nested Loops & CPU Cache Locality

Row-by-Row Traversal (Cache-Friendly)

for (int r = 0; r < m.length; r++) { for (int c = 0; c < m[r].length; c++) { process(m[r][c]); } }

Reads contiguous elements inside the same row array m[r] sequentially, maximizing CPU L1/L2 Cache Hits.

Column-by-Column Traversal

for (int c = 0; c < m[0].length; c++) { for (int r = 0; r < m.length; r++) { process(m[r][c]); } }

Jumps across different row objects on every inner step. Both take O(R×C) asymptotic time, but Row-Major is significantly faster in hardware.

3. Core Operations & Algorithms on 2D Matrices

3.1 Direct Coordinate Access & Update (m[r][c])
Time: O(1) Space: O(1)

Accessing or modifying any cell m[r][c] requires zero loops. The JVM resolves row reference m[r] and offsets directly to column c in constant time O(1), regardless of whether the matrix is 3×3 or 10,000×10,000.

// Direct O(1) read and write by (row, col) coordinates: int currentVal = m[r][c]; // Constant-time read: O(1) m[r][c] = newVal; // Constant-time in-place update: O(1)
3.2 Row-Wise, Column-Wise & Total Matrix Sum
Time: O(R×C) Space: O(1)

To compute the sum of each individual row, we reset a local accumulator rowSum = 0 at the beginning of each outer loop iteration r, accumulate m[r][c] across the inner loop, and add it to totalSum. Every cell is visited exactly once: T(R, C) = R × C = O(R×C).

int totalSum = 0; for (int r = 0; r < m.length; r++) { int rowSum = 0; // Reset accumulator for row r for (int c = 0; c < m[r].length; c++) { rowSum += m[r][c]; } totalSum += rowSum; System.out.println("Row " + r + " sum = " + rowSum); }
3.3 Find 2D Maximum & Minimum with Coordinates
Time: O(R×C) Space: O(1)

We initialize max = m[0][0] and min = m[0][0] along with their coordinate trackers (maxR, maxC) = (0, 0). A full nested traversal compares every cell against max and min, updating both the value and its coordinates whenever a new extreme is found.

int max = m[0][0], maxR = 0, maxC = 0; int min = m[0][0], minR = 0, minC = 0; for (int r = 0; r < m.length; r++) { for (int c = 0; c < m[r].length; c++) { if (m[r][c] > max) { max = m[r][c]; maxR = r; maxC = c; } if (m[r][c] < min) { min = m[r][c]; minR = r; minC = c; } } }
3.4 2D Linear Search in an Unsorted Matrix
Best: O(1) Worst: O(R×C)

When a matrix is unsorted, no row or column can be ruled out without inspection. We scan row-by-row until m[r][c] == target (returning new int[]{r, c} immediately) or until all R × C cells are exhausted.

public static int[] search2D(int[][] m, int target) { for (int r = 0; r < m.length; r++) { for (int c = 0; c < m[r].length; c++) { if (m[r][c] == target) return new int[]{r, c}; } } return new int[]{-1, -1}; }
3.5 Staircase Search in a Row & Column Sorted Matrix
Best: O(1) Worst: O(R+C)

When every row is sorted left-to-right and every column is sorted top-to-bottom, starting at the Top-Right Corner (r = 0, c = C - 1) turns every comparison into a decisive elimination of an entire row or column:

  • If m[r][c] == target → Found! Return {r, c}.
  • If m[r][c] > target → Everything below in column c is even larger; eliminate column c by moving left (c--).
  • If m[r][c] < target → Everything left in row r is even smaller; eliminate row r by moving down (r++).

Because r can increment at most R times and c can decrement at most C times, the worst-case number of steps is bounded by R + C = O(R+C) (e.g., at most 2,000 steps on a 1,000×1,000 matrix instead of 1,000,000!).

int r = 0, c = m[0].length - 1; // Start at Top-Right corner while (r < m.length && c >= 0) { if (m[r][c] == target) return new int[]{r, c}; else if (m[r][c] > target) c--; // Eliminate column c (move left) else r++; // Eliminate row r (move down) }
3.6 Primary & Secondary Diagonal Traversal & Sum
Time: O(N) Space: O(1)

In a square N × N matrix, the Primary Diagonal consists of cells where r == c (i.e., m[i][i]), and the Secondary (Anti) Diagonal consists of cells where r + c == N - 1 (i.e., m[i][N - 1 - i]). Consequently, we do not need nested loops! A single loop from i = 0 to N - 1 sums both diagonals in O(N) time, checking i != N - 1 - i to avoid counting the center cell twice when N is odd.

int n = m.length, sum = 0; for (int i = 0; i < n; i++) { sum += m[i][i]; // Primary Diagonal (r == c) if (i != n - 1 - i) { sum += m[i][n - 1 - i]; // Secondary Diagonal (skip center if odd N) } }
3.7 In-Place Square Matrix Transpose (m[r][c] ↔ m[c][r])
Time: O(N²) Space: O(1)

Transposing a square N × N matrix reflects it across its primary diagonal so that rows become columns. The inner loop must start at c = r + 1 (strictly the upper triangle) to swap m[r][c] with m[c][r] exactly once. Starting at c = 0 would swap every pair twice, returning the matrix to its original state! Total swaps = N(N - 1)/2 = O(N²) with O(1) auxiliary space.

for (int r = 0; r < n; r++) { for (int c = r + 1; c < n; c++) { // Upper triangle only (c > r) int temp = m[r][c]; m[r][c] = m[c][r]; m[c][r] = temp; } }
3.8 Horizontal Matrix Flip (Mirror Image / Row Reversal)
Time: O(R×C) Space: O(1)

A horizontal mirror flip reverses each row in-place using the Two-Pointer technique from Lecture 01 (left = 0, right = C - 1). Furthermore, combining In-Place Transpose (3.7) followed by Horizontal Flip (3.8) rotates a square matrix by 90° clockwise in-place!

for (int r = 0; r < m.length; r++) { int left = 0, right = m[r].length - 1; while (left < right) { int temp = m[r][left]; m[r][left] = m[r][right]; m[r][right] = temp; left++; right--; } }
3.9 Spiral Order Matrix Traversal (Boundary Peeling)
Time: O(R×C) Aux Space: O(1)

To traverse a matrix in a clockwise spiral, we maintain four shrinking boundary pointers: top = 0, bottom = R - 1, left = 0, and right = C - 1. In each cycle, we sweep the top row (→) and increment top++, sweep the right column (↓) and decrement right--, sweep the bottom row (←) and decrement bottom--, and sweep the left column (↑) and increment left++, visiting every cell exactly once in O(R×C) time.

int top = 0, bottom = R - 1, left = 0, right = C - 1; while (top <= bottom && left <= right) { for (int c = left; c <= right; c++) print(m[top][c]); top++; for (int r = top; r <= bottom; r++) print(m[r][right]); right--; if (top <= bottom) { for (int c = right; c >= left; c--) print(m[bottom][c]); bottom--; } if (left <= right) { for (int r = bottom; r >= top; r--) print(m[r][left]); left++; } }
