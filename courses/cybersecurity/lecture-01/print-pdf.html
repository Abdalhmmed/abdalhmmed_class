1. Foundational Cybersecurity Principles & Keyspace Analysis

In modern computer science, the security of any cryptographic system is never measured by keeping its source code or algorithm secret ("Security by Obscurity"), but rests on rigorous mathematical principles:

Kerckhoffs's Principle: "A cryptosystem should be secure even if everything about the system, except the key, is public knowledge." All modern standards (AES, RSA, SHA-256) are publicly peer-reviewed algorithms.

The Information Security Triad (CIA Triad)

Confidentiality

Preventing unauthorized disclosure of sensitive data, enforced via symmetric (AES) and asymmetric (RSA) encryption.

Integrity

Guaranteeing that data has not been altered or tampered with in transit or at rest, verified via cryptographic hashes (SHA-256) and MACs.

Availability

Ensuring authorized users have reliable, timely access to information and services while mitigating Denial-of-Service (DoS) attacks.

Keyspace Exploration & Brute-Force Resistance

The keyspace is the total number of possible distinct keys for an algorithm, equal to 2k where k is the key length in bits:

Key Length (k) Total Keyspace (2k) Estimated Brute-Force Time (at 1012 keys/sec) Security Verdict
8-bit 256 < 0.000001 seconds (Instant) Trivially Broken
56-bit (Legacy DES) 7.2 × 1016 ~ 20 hours on dedicated hardware Broken Since 1999
128-bit (AES-128) 3.4 × 1038 > 1019 years (Quintillions of years) Globally Secure
256-bit (AES-256) 1.15 × 1077 Exceeds the age of the universe by orders of magnitude Military / Post-Quantum Grade

2. Discrete Mathematics & Modular Arithmetic for Cryptography

Modular arithmetic is the mathematical cornerstone of modern cryptography. It bounds all operations within a finite ring Zm = {0, 1, 2, ..., m - 1}, preventing numeric overflow and creating one-way trapdoor functions:

a ≡ b (mod m) ⇔ m divides (a - b)

Extended Euclidean Algorithm

Used to compute the modular multiplicative inverse d = e-1 mod φ(n) satisfying (e · d) mod φ(n) = 1. Without this algorithm, RSA private key generation would be computationally infeasible.

// Compute modular multiplicative inverse: d = e^-1 mod phi public static int modInverse(int e, int phi) { int t = 0, newT = 1; int r = phi, newR = e; while (newR != 0) { int q = r / newR; int tempT = t - q * newT; t = newT; newT = tempT; int tempR = r - q * newR; r = newR; newR = tempR; } if (r > 1) return -1; // Not invertible if (t < 0) t += phi; return t; }

Fast Modular Exponentiation (Square-and-Multiply)

To evaluate C = Me mod n over 2048-bit integers, we cannot compute Me directly (the intermediate result would exceed all memory on Earth). Instead, the Square-and-Multiply algorithm reduces modulo n at every step, completing in logarithmic time O(log e).

public static byte[] xorCipher(byte[] data, byte[] key) { byte[] cipher = new byte[data.length]; for (int i = 0; i < data.length; i++) { cipher[i] = (byte) (data[i] ^ key[i]); // Single-cycle hardware bitwise XOR } return cipher; }
Fatal Key Reuse Vulnerability (Two-Time Pad Trap): If two messages P1 and P2 are encrypted with the same key stream K:
C1 ⊕ C2 = (P1 ⊕ K) ⊕ (P2 ⊕ K) = P1 ⊕ P2
The secret key cancels out completely, allowing attackers to recover both plaintexts!

4. AES Block Cipher Architecture & SPN Network

Algorithm 3: Advanced Encryption Standard (AES - Rijndael) Global Symmetric Gold Standard

AES processes data in fixed 128-bit blocks organized as a 4 × 4 byte State Matrix. The state undergoes 10 rounds (for 128-bit keys), 12 rounds (192-bit), or 14 rounds (256-bit), executing four transformations per round:

1. SubBytes (Non-Linear Confusion):

Replaces each byte using the Rijndael S-Box derived from multiplicative inverses in Galois Field GF(28) to defeat linear and differential cryptanalysis.

2. ShiftRows & 3. MixColumns (Diffusion):

Cyclically shifts rows (by 0, 1, 2, 3 bytes) and multiplies columns over GF(28) so a single bit change diffuses across the entire 16-byte state.

Row-wise cyclic permutation (Diffusion) mixColumns(state); // 3. Column mixing in Galois Field GF(2^8) addRoundKey(state, roundKey); // 4. XOR state with derived Round Key }
Algorithm 4: RSA Public-Key Cryptography (Rivest–Shamir–Adleman) Asymmetric Public-Key

Formal Mathematical Steps for RSA Key Generation & Encryption:

  1. Generate two large distinct secret primes p and q, and compute the public modulus n = p × q.
  2. Compute Euler's totient function: φ(n) = (p - 1)(q - 1).
  3. Choose public exponent e (commonly 65537) such that gcd(e, φ(n)) = 1.
  4. Compute secret private key d = e-1 mod φ(n) using the Extended Euclidean Algorithm.
  5. Encryption: C = Me mod n | Decryption: M = Cd mod n.
// RSA Implementation using Java BigInteger BigInteger n = p.multiply(q); BigInteger phi = p.subtract(BigInteger.ONE).multiply(q.subtract(BigInteger.ONE)); BigInteger d = e.modInverse(phi); // Secret Private Exponent BigInteger C = M.modPow(e, n); // Encrypt with Public Key (e, n) BigInteger decrypted = C.modPow(d, n); // Decrypt with Private Key (d, n)

1. المبادئ التأسيسية للأمن السيبراني وفضاء المفاتيح

في علوم الحاسوب المتقدمة، لا يُقاس أمان أي نظام تشفيري بمدى تعقيد الكود البرمجي أو محاولة إخفاء طريقة عمله، بل يستند إلى قاعدتين لا حياد عنهما:

مبدأ كيركهوفس (Kerckhoffs's Principle): «أمان النظام يجب ألا يعتمد على سرية الخوارزمية، بل على سرية المفتاح فقط.» جميع الخوارزميات القياسية (AES, RSA, SHA-256) علنية ومفتوحة المصدر ومفحوصة عالمياً.

مثلث أمن المعلومات (CIA Triad) وتوسيع AAA

السرية (Confidentiality)

منع الوصول غير المصرح به لقراءة محتوى البيانات، ويتحقق عبر خوارزميات التشفير المتماثل (AES) وغير المتماثل (RSA).

السلامة (Integrity)

التيقن من أن البيانات لم يتم التلاعب بها أو تعديلها أثناء النقل أو التخزين، ويتحقق عبر دوال الهاش (SHA-256).

الإتاحة (Availability)

ضمان قدرة المستخدمين المصرح لهم على الوصول للخدمة والبيانات في أي وقت ومنع هجمات حجب الخدمة (DoS).

حساب فضاء المفاتيح (Keyspace Exploration) وهجمات القوة الغاشمة

فضاء المفاتيح هو إجمالي عدد المفاتيح الممكنة لخوارزمية ما، ويساوي $2^k$ حيث $k$ يمثل طول المفتاح بالبتات:

طول المفتاح (k) عدد الاحتمالات ($2^k$) الزمن المتوقع للكسر (بسرعة 1 تريليون مفتاح/ثانية) حكم الأمن السيبراني

56 بت (DES القديم) $7.2 \times 10^{16}$ ~ 20 ساعة بحاسوب مخصص مكسور عملياً منذ 1999
128 بت (AES-128) $3.4 \times 10^{38}$ > مليار مليار سنة! آمن تجارياً وعالمياً
256 بت (AES-256) $1.15 \times 10^{77}$ يفوق عمر الكون بمليارات المرات مناعة عسكرية وفلكية

2. الرياضيات المتقطعة وحساب الموديلار للتشفير

الحساب النمطي (Modular Arithmetic) هو حجر الزاوية لكل أنظمة التشفير الحديثة؛ حيث يحصر النتائج داخل حلقة منتهية $\mathbb{Z}_m = \{0, 1, 2, \dots, m-1\}$ مما يمنع حدوث فيضان الذاكرة (Buffer Overflow):

a ≡ b (mod m) ⟺ m divides (a - b)

خوارزمية إقليدس الموسعة (Extended Euclidean Algorithm)

تُستخدم لحساب المعكوس الضربي التشفيري $d = e^{-1} \pmod{\phi(n)}$، والذي يحقق الشرط الأساسي: $e \cdot d \equiv 1 \pmod{\phi(n)}$. بدون هذه الخوارزمية يستحيل توليد مفاتيح RSA في زمن معقول.

// حساب المعكوس الضربي التشفيري d = e^-1 mod phi public static int modInverse(int e, int phi) { int t = 0, newT = 1; int r = phi, newR = e; while (newR != 0) { int q = r / newR; int tempT = t - q * newT; t = newT; newT = tempT; int tempR = r - q * newR; r = newR; newR = tempR; } if (r > 1) return -1; // لا يوجد معكوس if (t < 0) t += phi; return t; }

الأس السريع بالحساب الموديلاري (Fast Modular Exponentiation)

لحساب $C = M^e \pmod n$ عندما تكون الأرقام مكونة من آلاف البتات، لا يمكن رفع العدد أولاً ثم أخذ باقي القسمة (لأن الناتج سيتطلب ذاكرة هائلة). نستخدم خوارزمية التربيع والضرب (Square-and-Multiply) التي تنفذ العملية بزمن $O(\log e)$ فقط.

4. معمارية تشفير الكتل AES وشبكة SPN

العملية 3: معيار التشفير المتقدم (AES - Rijndael) المعيار الذهبي العالمي المعتمد

يعتمد معيار AES على كتلة ثابتة بحجم 128-بت مقسمة في مصفوفة حالة $4 \times 4$ من البايتات (State Matrix). تمر الكتلة عبر 10 جولات (لمفتاح 128-بت) أو 14 جولة (لمفتاح 256-بت):

العملية 4: خوارزمية RSA للتشفير غير المتماثل (Rivest–Shamir–Adleman) Asymmetric Public-Key

الخطوات الرياضية الصارمة لتوليد المفاتيح والتشفير:

  1. اختيار عددين أوليين سريين ضخمين $p$ و $q$، وحساب المعامل العام: $n = p \times q$.
  2. حساب دالة أويلر للمؤشر: $\phi(n) = (p - 1)(q - 1)$.
  3. اختيار المفتاح العام $e$ (عادة 65537) بحيث يكون أولياً نسبياً مع $\phi(n)$؛ أي $\gcd(e, \phi(n)) = 1$.
  4. حساب المفتاح الخاص السري $d = e^{-1} \pmod{\phi(n)}$ عبر خوارزمية إقليدس الموسعة.
  5. التشفير: $C = M^e \pmod n$ | فك التشفير: $M = C^d \pmod n$.
// تطبيق RSA باستخدام فئة BigInteger في Java BigInteger n = p.multiply(q); BigInteger phi = p.subtract(BigInteger.ONE).multiply(q.subtract(BigInteger.ONE)); BigInteger d = e.modInverse(phi); // المفتاح الخاص السري BigInteger C = M.modPow(e, n); // التشفير بالمفتاح العام (e, n) BigInteger decrypted = C.modPow(d, n); // فك التشفير بالمفتاح الخاص (d, n)

/** * مختبر الأمن السيبراني وعلم التشفير بلغة Java * إعداد: م. عبدالحميد هلال دعبان - العام الجامعي 2026-2027م */ import javax.crypto.Cipher; import javax.crypto.KeyGenerator; import javax.crypto.SecretKey; import javax.crypto.spec.GCMParameterSpec; import java.security.KeyPair; import java.security.KeyPairGenerator; import java.security.MessageDigest; import java.security.Signature; public class MasterCryptoReference { // 1. تشفير متماثل AES-256 بوضع GCM المصادق public static byte[] encryptAES(byte[] data, SecretKey key, byte[] iv) throws Exception { Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding"); cipher.init(Cipher.ENCRYPT_MODE, key, new GCMParameterSpec(128, iv)); return cipher.doFinal(data); } // 2. بصمة الهاش SHA-256 public static byte[] hashSHA256(byte[] data) throws Exception { MessageDigest md = MessageDigest.getInstance("SHA-256"); return md.digest(data); } // 3. التوقيع الرقمي بـ RSA-2048 public static byte[] signData(byte[] data, KeyPair pair) throws Exception { Signature signer = Signature.getInstance("SHA256withRSA"); signer.initSign(pair.getPrivate()); signer.update(data); return signer.sign(); } }
