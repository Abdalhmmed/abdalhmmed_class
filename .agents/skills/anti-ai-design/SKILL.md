# Anti-AI Design Skill

## Primary Objective
Create distinctive, professional and purposeful interfaces.
Avoid generic AI-generated website aesthetics.

## Design Rules

### 1. Avoid Repetitive Patterns
- Do not reuse the same layout across every page.
- Do not turn every section into a card.
- Avoid repetitive grids and identical component structures.
- Each page must have a layout appropriate to its purpose.

### 2. Avoid Generic AI Aesthetics
- No unnecessary gradients.
- No excessive rounded corners.
- No excessive shadows or glowing effects.
- Avoid random decorative circles and abstract shapes.
- Avoid unnecessary glassmorphism.
- Do not use purple-to-blue gradients as a default.

### 3. Typography
- Establish a clear typography hierarchy.
- Use appropriate font weights and sizes.
- Avoid using too many font sizes.
- Prioritize readability and visual balance.
- Support Arabic RTL typography when required.

### 4. Layout and Composition
- Use intentional whitespace.
- Create visual hierarchy.
- Use asymmetrical layouts when appropriate.
- Avoid excessive centered content.
- Make each section visually distinct.

### 5. Component Design
- Design components based on their actual function.
- Avoid using identical card styles everywhere.
- Use tables, lists, split layouts, timelines and other patterns when appropriate.
- Keep components consistent without making them identical.

### 6. Before Designing
1. Inspect the existing project.
2. Understand its purpose and target audience.
3. Inspect existing design patterns.
4. Choose a suitable visual direction.
5. Avoid copying common AI-generated templates.

### 7. Final Review
Before completing the work, check:
- Does the interface look generic?
- Are too many cards being used?
- Are sections visually repetitive?
- Is the visual hierarchy clear?
- Is the design consistent with the project identity?
- Is the responsive layout correct?

If the design looks like a generic AI-generated template,
reconsider the composition before finishing.
