## 📚 الأقسام والمجلدات الرئيسية

### 1. [مجلد المعمارية ونظام التصميم (`architecture/`)](architecture/)
يحتوي على الوثيقة المرجعية القياسية لبناء الصفحات والمحاكيات:
- **[دليل المعمارية ونظام التصميم للمنصة](architecture/ARCHITECTURE_AND_DESIGN_GUIDE.md):**
  - شجرة الملفات والروابط النسبية.
  - متغيرات CSS للألوان والوضع الليلي/النهاري.
  - معيار أيقونات Font Awesome 6 ومنع الإيموجيات في أدوات التحكم.
  - معمارية مشغل المحاكاة بنمط مسجل الحالات (State-Recorder Engine) واتجاه RTL.
  - هندسة صفحة الطباعة وملزمة الـ PDF القياسية A4.

### 2. [مجلد التحليلات البيداغوجية والتعليمية (`pedagogy/`)](pedagogy/)
يحتوي على الدراسات الأكاديمية التي تحلل أساليب التدريس ووسائل الإيضاح:
- **[تحليل أسلوب الدرس في المحاضرة الأولى (المصفوفات)](pedagogy/LECTURE_01_STYLE_ANALYSIS.md):**
  - الرؤية الفلسفية للتعلم البصري التجريبي النشط ومحاكاة الذاكرة.
  - منهجية "التعقيد أولاً" (Complexity-First Mindset).
- **[تحليل أسلوب معمل محرك الألعاب Unity 2D](pedagogy/UNITY_2D_STYLE_ANALYSIS.md):**
  - الرؤية التعليمية لـ Rule Tile وأتمتة البيئات والأنيميشن (إعداد: أ. أحمد علي | تصميم: م. عبدالحميد).
  - منهجية التجريد المفهومي قبل النقر والتقييم المعياري الشفاف.

### 3. [مجلد الأدلة الإرشادية والمعايير (`guides/`)](guides/)
يحتوي على خطوات العمل السريعة وإرشادات التطوير:
