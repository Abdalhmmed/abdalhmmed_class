## 1. المقدمة والرؤية الفلسفية للدرس السيبراني

تعتمد المحاضرة الأولى لمقرر التشفير والأمن السيبراني لطلبة السنة الثالثة علوم حاسوب على فلسفة تعليمية حاسمة:
> **"الأمن السيبراني والتشفير ليسا مجرد استدعاء دوال جاهزة أو كلمات سر معقدة، بل هما براهين رياضية متقطعة، وعمليات منطقية على مستوى البتات (Bitwise Logic)، وهندسة صارمة لإدارة الثقة في بيئة معادية."**

تم اختيار وتصميم نظام الألوان بهوية **خضراء زمردية تكنولوجية (Cyber Emerald Green: `#059669` / `#10b981`)** لتعكس أجواء الأمان السيبراني (Shield & Defense)، مع محاكاة بصرية تجعل الطالب يرى حركة البتات وتغيرات الحالات خطوة بخطوة.

## 3. النموذج الثلاثي لشرح خوارزميات التشفير (Tripartite Teaching Model)

التزاماً بمعايير المنصة، تنقسم كل عملية تشفيرية إلى الشرائح الثلاث:

| الشريحة التعليمية | المضمون والدور الوظيفي | الهدف البيداغوجي لطلبة علوم الحاسوب |
| :--- | :--- | :--- |
| **① الفكرة (The Intuition)** | صياغة الفكرة بلغة طبيعية + خطوات الخوارزمية الرياضية + تشبيه واقعي ملموس. | كسر رهبة الرموز الرياضية وتكوين نموذج ذهني بديهي. |
| **② التنفيذ خطوة بخطوة (Execution)** | محاكي تفاعلي حي يعكس حركة البتات والخانات + تظليل متزامن لكود Java + لوحة المتغيرات والعدادات. | معاينة التحويلات البتية وجداول الصناديق (S-Box) لحظة بلحظة. |
| **③ التحليل والأمان (Security Analysis)** | تحليل فضاء المفاتيح (Keyspace) + أساليب الهجوم (Cryptanalysis) + معايير الأمان ومواصفات NIST. | تدريب الطالب كمهندس أمن سيبراني يقيم المناعة الرياضية للخوارزمية. |

## 4. الربط بين المفاهيم الرياضية والبتات الثنائية

يركز الدرس لطلبة السنة الثالثة على الربط بين:
1. **العمليات الرياضية الحسابية:** مثل الحساب النمطي $\pmod m$ واللوغاريتم المنفصل (Discrete Logarithm Problem).
2. **العمليات المنطقية على العتاد والمعالج:** مثل عملية $XOR$ ($\oplus$) وسرعتها الفائقة في دورة ساعة واحدة.
3. **مبدأ الشانوني للتشويش والانتشار (Confusion & Diffusion):** تجسيد كيف يؤدي تبديل بايت واحد إلى قلب نصف بتات الناتج في دوال الهاش ومصفوفات AES.

## 5. التفاعل البصري وتتبع الحالات الحية بالهوية الخضراء

- اعتماد متغيرات الـ CSS الخضراء الزمردية (`--brand: #059669; --brand-hover: #047857; --brand-soft: #ecfdf5`).
- مشغل المحاكاة الموجه لليمين لليسار (RTL-First Controls): البداية ⏭، السابق →، تشغيل/إيقاف ▶، التالي ←، النهاية ⏮.
- عدادات الجهد الحسابي المتخصصة بالتشفير:
  - 🔄 **عدد العمليات المنطقية / البتية (Bitwise Ops):** تتبع عمليات XOR، Shift، و Modulo.
  - 🔑 **فضاء الاحتمالات المفحوص (Keyspace Tried):** تتبع محاولات فك الشفرة أو المقارنات.
  - ⚡ **البتات المتغيرة (Avalanche Bit Flips):** رصد أثر الانهيار الثلجي في دوال الهاش.
