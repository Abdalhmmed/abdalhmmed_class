# دليل إضافة وتوسيع المقررات والمحاضرات
## Practical Guide for Adding New Courses & Lectures

---

## 🎯 الغرض من هذا الدليل
يوفر هذا الدليل الخطوات العملية المباشرة للمطورين ونماذج الذكاء الاصطناعي (AI Prompting) لإنشاء محاضرات جديدة أو مقررات جامعية جديدة في المنصة، مع الالتزام التام بنظام التصميم ومعمارية الملفات المعتمدة.

---

## 1. شجرة إضافة محاضرة جديدة (Lecture Structure)

عند إضافة محاضرة جديدة لأي مقرر (مثل المحاضرة الثانية في هياكل البيانات `Linked Lists`):

### أ. إنشاء مجلد المحاضرة:
```text
courses/data-structures/lecture-02/
├── README.md              # دليل المحاضرة ومقدمتها
├── interactive.html       # صفحة الشرح التفاعلي ومحاكي الذاكرة
└── print-pdf.html         # نسخة الملزمة الأكاديمية والطباعة A4
```

### ب. القواعد البرمجية لملف `interactive.html`:
1. **ملف متكامل ومستقل (Self-Contained Single File):**
   - يحتوي الكود على الـ HTML و CSS و JavaScript داخل ملف واحد.
   - لا يستدعي أي حزم npm أو أطر عمل ثقيلة.
   - يعتمد فقط على خطوط Google Fonts ومكتبة الأيقونات Font Awesome 6 عبر CDN.
2. **محرك المحاكاة ومسجل الحالات (State-Recorder Engine):**
   - تسجيل مصفوفة خطوات متسلسلة (`steps`) تحتوي على لقطة لحالة الذاكرة لكل خطوة.
   - تظليل السطر البرمجي النشط في لغة Java تزامناً مع الخطوة.
   - تحديث عدادات القراءات، الكتابات، والمقارنات.
3. **أزرار التحكم باتجاه RTL:**
   - الترتيب الإلزامي: `⏭` البداية ← `→` السابق ← `▶` تشغيل/إيقاف ← `←` التالي ← `⏮` النهاية.
4. **شريط التنقل العلوي الموحد (Topbar):**
   - رابط العودة للرئيسية (`index.html`).
   - رابط نسخة الطباعة (`print-pdf.html`).
   - اسم وصورة المحاضر: م. عبدالحميد هلال دعبان.
   - أدوات: وضع العرض، قلم الشرح، وتبديل الوضع الليلي.

## 2. القواعد البرمجية لملف `print-pdf.html`
1. **أبعاد الصفحة القياسية:**
   ```css
   @page {
     size: A4 portrait;
     margin: 14mm 16mm;
   }
   ```
2. **صفحة الغلاف الأكاديمية (`.cover-page`):**
   - اسم المقرر ورقم المحاضرة واسم المحاضر والعام الجامعي 2026-2027م.
   - فاصل صفحة إجباري بعد الغلاف (`break-after: page;`).
3. **منع انشطار الجداول والأكواد:**
   ```css
   .op-card, table, .diagram-stage, .code-block {
     break-inside: avoid !important;
     page-break-inside: avoid !important;
   }
   ```
4. **المخططات الشريطية الثابتة للذاكرة:**
   - عرض العناوين الفيزيائية، الفهارس، وقيم الخلايا بشكل شريطي متناسق جاهز للطباعة.

## 3. إضافة مقرر دراسي جديد (New Course)

لإضافة مقرر دراسي جديد بالكامل (مثل الخوارزميات أو OOP):
1. أنشئ مجلداً باسم المقرر داخل `courses/`، مثلاً: `courses/algorithms/`.
2. أنشئ داخله مجلد المحاضرة الأولى: `courses/algorithms/lecture-01/`.
3. حدّث بطاقة المقرر في الصفحة الرئيسية `index.html` لإضافة رابط الانتقال المباشر.
